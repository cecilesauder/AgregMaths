🧶 Le tour de crochet
Une image concrète pour "voir" ce que fait un groupe cyclique
Imagine un tour de crochet avec n mailles posées en cercle, numérotées 0, 1, 2... À chaque étape, ton fil saute de k mailles. La question "quel est l'ordre de k" devient très concrète : combien de sauts avant que le fil revienne pile sur la maille 0 ?
Maille de départ : 0 — Position actuelle : 0
Sauts effectués : 0

🎉 Le fil est revenu à la maille 0 !

🧶 Traduction en langage groupes

Le nombre de sauts pour revenir à 0 = l'ordre de k. L'ensemble des mailles touchées par ton fil = le sous-groupe engendré ⟨k⟩. Si ton étoile ne couvre pas toutes les mailles, le nombre d'étoiles nécessaires pour tout couvrir (en partant de mailles différentes) = pgcd(k,n) — et chaque étoile a exactement "ordre(k)" mailles.
