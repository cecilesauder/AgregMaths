Fiches de cours — Option A

1. Fondements des probabilités Fondements
tribu mesure variable aléatoire espérance
Définition — Espace de probabilité Un espace de probabilité est un triplet (Ω, 𝒜, P) où Ω est l'espace des événements élémentaires, 𝒜 une tribu sur Ω (σ-algèbre), et P une mesure de probabilité : P(Ω)=1, σ-additivité.
Définition — Variable aléatoire réelle Une v.a.r. X : (Ω, 𝒜) → (ℝ, ℬ(ℝ)) est une application mesurable. Sa loi est la mesure image P∘X⁻¹ sur ℝ.
Théorème de transfert Si X est une v.a. et h : ℝ → ℝ borélienne, alors E[h(X)] = ∫ h(x) dP_X(x) dès que cette intégrale est définie.
Le jury signale que le théorème de transfert est souvent mal énoncé (oubli de l'hypothèse d'intégrabilité) ou mal appliqué. Soigner les hypothèses.

Lois usuelles à maîtriser parfaitement

  • Discrètes : Bernoulli, Binomiale B(n,p), Poisson P(λ), Géométrique, Hypergéométrique, Multinomiale
  • Continues : Uniforme U[a,b], Exponentielle Exp(λ), Normale N(μ,σ²), Gamma Γ(α,β), Chi-deux χ²(n), Student t(n), Cauchy

Indépendance

Définition — Indépendance Des v.a. X₁,…,Xₙ sont indépendantes si et seulement si la loi jointe est le produit des lois marginales : P_{(X₁,…,Xₙ)} = P_{X₁} ⊗ … ⊗ P_{Xₙ}.

Attention : deux à deux indépendantes ≠ mutuellement indépendantes (contre-exemple classique à connaître).

2. Convergences et théorèmes limites Convergence
p.s. en proba en loi L² LGN · TCL

Hiérarchie des convergences

Implications (à sens unique) p.s. ⟹ en proba ⟹ en loi
Lᵖ (p≥1) ⟹ en proba
⚠ Aucune réciproque en général. Connaître des contre-exemples pour chaque flèche manquante.
Loi forte des grands nombres (Kolmogorov) Si (Xₙ) i.i.d. avec E[|X₁|] < ∞, alors X̄ₙ = (X₁+…+Xₙ)/n → E[X₁] presque sûrement.
Théorème Central Limite (Lindeberg-Lévy) Si (Xₙ) i.i.d., E[X₁]=μ, Var(X₁)=σ² < ∞, alors √n(X̄ₙ - μ)/σ → N(0,1) en loi.
Le jury insiste : savoir démontrer le TCL via les fonctions caractéristiques (développement de log φ(t/√n) à l'ordre 2). C'est un développement classique à avoir en tête.

Fonctions caractéristiques

Définition φ_X(t) = E[e^{itX}]. Caractérise la loi de X. Inversion : si φ_X ∈ L¹, alors X a une densité f_X = (2π)⁻¹ ∫ e^{-itx} φ_X(t) dt.

Propriété : φ_{X+Y} = φ_X · φ_Y si X,Y indépendantes.

Lemme de Borel-Cantelli

Borel-Cantelli Si Σ P(Aₙ) < ∞ alors P(lim sup Aₙ) = 0.
Réciproque (si les Aₙ sont indépendants) : si Σ P(Aₙ) = ∞ alors P(lim sup Aₙ) = 1.
3. Chaînes de Markov Markov
propriété de Markov classification mesure stationnaire ergodicité
Définition — Chaîne de Markov homogène (Xₙ)ₙ≥₀ à valeurs dans E (dénombrable) est une chaîne de Markov homogène de matrice de transition P si :
P(Xₙ₊₁ = j | X₀,…,Xₙ) = P(Xₙ₊₁ = j | Xₙ) = P(Xₙ, j)

Classification des états

  • Récurrent : P(Xₙ = i pour une infinité de n | X₀=i) = 1
  • Transient : probabilité de retour < 1
  • Récurrent positif : récurrent avec temps de retour d'espérance finie
  • Récurrent nul : récurrent mais E[T_i | X₀=i] = ∞
  • Périodique : période d(i) = pgcd{n≥1 : Pⁿ(i,i)>0}
Théorème ergodique Si la chaîne est irréductible, apériodique et récurrente positive avec mesure stationnaire π, alors pour toute loi initiale : P(Xₙ = j) → π(j) quand n → ∞.
Existence et unicité de la mesure stationnaire Une chaîne irréductible admet une mesure stationnaire si et seulement si elle est récurrente positive. Elle est alors unique (à une constante près pour les mesures, unique pour les probabilités).
Connaître des exemples concrets : marche aléatoire sur ℤ (récurrente nulle), urne de Pólya, file d'attente M/M/1.

Simulation Scilab

// Simulation d'une chaîne de Markov
P = [0.7 0.3; 0.4 0.6]; // matrice de transition
n = 1000; X = zeros(1, n); X(1) = 1;
for k = 1:n-1
    u = rand();
    if u < P(X(k), 1) then X(k+1) = 1; else X(k+1) = 2; end
end
disp([sum(X==1)/n, sum(X==2)/n]) // fréquences empiriques
4. Martingales Martingale
filtration convergence arrêt optionnel
Définition — Filtration et martingale (𝒻ₙ)ₙ≥₀ est une filtration si 𝒻₀ ⊂ 𝒻₁ ⊂ … ⊂ 𝒻. (Mₙ) est une martingale par rapport à (𝒻ₙ) si :
(i) Mₙ est 𝒻ₙ-mesurable, (ii) E[|Mₙ|] < ∞, (iii) E[Mₙ₊₁ | 𝒻ₙ] = Mₙ p.s.
Théorème de convergence des martingales (Doob L¹) Si (Mₙ) est une martingale bornée dans L¹ (i.e. sup E[|Mₙ|] < ∞), alors Mₙ → M∞ p.s. et dans L¹.
Théorème d'arrêt optionnel (Doob) Si T est un temps d'arrêt borné et (Mₙ) une martingale, alors E[M_T] = E[M₀].

Applications classiques à l'agrégation :

  • Probabilité de ruine du joueur (martingale exponentielle)
  • Marche aléatoire simple : Sₙ = X₁+…+Xₙ est une martingale si E[X₁]=0
  • Sₙ² - n·Var(X₁) est une martingale
  • Processus de Galton-Watson
5. Statistique inférentielle Stats
estimation IC tests régression

Estimation ponctuelle

Propriétés d'un estimateur T_n de θ
  • Sans biais : E_θ[T_n] = θ pour tout θ
  • Consistant : T_n → θ en probabilité quand n→∞
  • Efficace : atteint la borne de Cramér-Rao
Borne de Cramér-Rao Pour tout estimateur sans biais T_n de θ : Var_θ(T_n) ≥ 1 / (n · I(θ)) où I(θ) = E[(∂/∂θ log f(X;θ))²] est l'information de Fisher.

Intervalles de confiance

IC de niveau 1-α pour μ (variance connue σ²) : [X̄_n ± z_{α/2} · σ/√n] où z_{α/2} est le quantile de N(0,1).

Tests d'hypothèse

  • Erreur type I : rejeter H₀ à tort (risque α = niveau du test)
  • Erreur type II : ne pas rejeter H₀ faux (risque β)
  • Puissance : 1 - β
Lemme de Neyman-Pearson Le test le plus puissant de niveau α pour H₀:θ=θ₀ contre H₁:θ=θ₁ est le test du rapport de vraisemblance : rejeter H₀ si L(θ₁;x)/L(θ₀;x) > k.

Tests classiques

  • Test du χ² : adéquation à une loi, indépendance dans un tableau de contingence
  • Test de Student : comparaison de moyennes
  • Test de Fisher : comparaison de variances

Régression linéaire

Modèle : Y = Xβ + ε avec ε ~ N(0, σ²Iₙ). Estimateur MCO : β̂ = (XᵀX)⁻¹XᵀY. Sans biais, efficace (Gauss-Markov).

Scilab est gratuit et disponible sur Ubuntu. Il te faudra principalement : générer des variables aléatoires, simuler des processus (chaînes de Markov, marches aléatoires), calculer des statistiques, tracer des graphiques. La syntaxe est proche de MATLAB.

// Variables et opérations

    disp(i^2)

// Normale N(0,1)

Statistiques descriptives et graphiques

// Statistiques
x = grand(1, 500, 'nor', 2, 1);
disp(mean(x))      // moyenne
disp(variance(x))  // variance
disp(stdev(x))     // écart-type

// Histogramme
histplot(20, x)
xtitle('Histogramme N(2,1)', 'x', 'fréquence')

// Tracé de la densité théorique par-dessus
t = linspace(-2, 6, 200);
plot(t, exp(-(t-2).^2/2) / sqrt(2*%pi), 'r')

Simulation : convergence du TCL

// Illustration du TCL : moyennes de Bernoulli(0.3)
N = 5000; n = 30; p = 0.3;
moyennes = zeros(1, N);
for i = 1:N
    X = grand(1, n, 'bin', 1, p);
    moyennes(i) = (mean(X) - p) / sqrt(p*(1-p)/n);
end
histplot(30, moyennes)
t = linspace(-4, 4, 200);
plot(t, exp(-t.^2/2)/sqrt(2*%pi), 'r')
xtitle('TCL en action', 'valeur normalisée', 'densité')

Conseils du jury — Sessions 2024 & 2025

Ces extraits sont tirés des rapports officiels de jury. Ils définissent ce qui est vraiment attendu.

Sur les leçons (épreuves orales 1 et 2)

Maîtriser ce qu'on présente, pas tout présenter : "Des connaissances des bases fermement maîtrisées et intelligemment utilisées valent mieux qu'un étalage de savoirs emmagasinés sans recul et à peine digérés. Une maîtrise avérée et solide des bases assure déjà une note très convenable."
Les 6 premières minutes : "La candidate ou le candidat devrait s'imaginer dans la situation où il doit introduire à un auditoire, pendant 6 minutes, une leçon destinée à être développée sur plusieurs séances. Quel est l'intérêt du sujet ? Comment se positionne-t-il dans un paysage mathématique plus large ?"
Faire des dessins : "Le jury se désole du très petit nombre de candidats qui ont le réflexe de faire un dessin lorsque c'est pertinent. C'est pourtant un moyen extrêmement efficace pour faire saisir l'idée d'une preuve."
Exemples obligatoires : "Les leçons doivent être illustrées avec des exemples judicieusement choisis. De nombreux titres se terminent par 'exemples et applications' : le jury attend que le plan soit riche en exemples."
Le plan écrit (3 pages max) : "Il doit définir avec suffisamment de précision les notions mathématiques introduites, donner les énoncés complets (notamment les hypothèses) des résultats fondamentaux, citer des exemples et des applications."

Sur la modélisation option A

Partir du concret : "C'est une épreuve de modélisation. On doit sentir que les maths sont au service du problème concret. Partir d'un problème concret est très apprécié."
Aller-retour constant : "Durant la présentation, il doit y avoir un aller-retour régulier entre les résultats mathématiques énoncés et/ou démontrés, les simulations, la modélisation et les réponses aux problématiques."
La simulation compte : "Typiquement, une simulation originale peut faire l'objet d'une valorisation car elle est originale. L'utilisation d'un logiciel nécessite de l'habitude — il faut s'entraîner avant."
Apporter des éléments absents du texte : "Plus vous apportez d'éléments nouveaux (absents du texte) et pertinents, mieux c'est. Choisissez les preuves sur lesquelles vous êtes le plus à l'aise."

Sur le concours spécial docteurs

Le dossier scientifique : "Le dossier (12 pages max) présente le parcours, les travaux de recherche et les activités d'enseignement. La mise en perspective didactique est évaluée : aptitude à rendre ses travaux accessibles à un public de non-spécialistes."
Chiffres session 2024 : 365 postes ouverts au concours externe + 15 postes au concours spécial docteurs. Sur 2390 inscrits, 1209 présents aux deux épreuves. Le jury est bienveillant et cherche à valoriser les candidats.
